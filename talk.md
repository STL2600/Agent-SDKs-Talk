# Vendor Specific
 
::: notes

Only usable with a specific LLM provider.

:::
 
 ## OpenAI Agents SDK

 - Python & TypeScript
 - Successor to "Swarm" (their experimental toy)
 - Minimal primitives: agents, handoffs, guardrails, sessions
 - Built-in tracing dashboard
 - Works with 100+ LLMs via the OpenAI API

::: notes

 - Kindof a lie, because a lot of providers support the OpenAI API.
 - Age: Swarm dropped Oct 2024; the real SDK shipped Mar 11, 2025 on top of the Responses API.
 - Apr 2026 update added sandboxed agents / a safety harness for enterprises.

:::

 ## OpenAI Agents SDK
 
  - Best for third party support

 ## AWS Strands

 - Python & TypeScript
 - Remote session manager for persisted state
 - Agent to Agent protocol
 - Deep MCP integration

::: notes

 - Standout: it's model-agnostic despite being AWS's — Bedrock
 - The native A2A protocol support is a differentiator vs. the others.

:::

 ## AWS Strands
 
  - Very clearly playing second fiddle to AgentCore

 ## Google ADK

 - Most polyglot: Python, Java, Go, TypeScript
 - Bidirectional audio/video streaming
 - Built-in evaluation tooling

::: notes

 - Standout: bidirectional live audio/video streaming is genuinely unique vs. the other three. Broadest language coverage too.
 - Lock at the deploy layer (Vertex AI / Gemini ecosystem).

:::

 ## Google ADK
 
 - Probably best for "assistants" 

 ## Anthropic Agent SDK

 - Python & TypeScript
 - The exact same harness that powers Claude Code
 - Battle-tested agent loop, memory, context management
 - Strong on long-running autonomous tasks
 - Subagents & session forking

::: notes

 - Age: started as the Claude Code SDK, renamed to Claude Agent SDK
 - Tightly vendor-bound of the four — built around Claude models.

:::

 ## Anthropic Agent SDK
 
  - Most "Batteries Included"
